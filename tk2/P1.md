# P1 – Übungstest Tastenkombinationen

**Bereich:** Tastenkombinationen A1–A7  
**Zeit:** ca. 35–40 Minuten  
**Punkte:** 41 + max. 2 Bonuspunkte  
**Hilfsmittel:** keine Kursseiten oder Merkblätter öffnen

---

Schreibe die **passende Tastenkombination** auf.

1. Markierten Text kopieren
2. Markierten Text ausschneiden
3. Kopierten Inhalt einfügen
4. Text möglichst ohne ursprüngliche Formatierung einfügen
5. Letzten Schritt rückgängig machen
6. Eine rückgängig gemachte Aktion wiederherstellen
7. Aktuelles Dokument speichern
8. Gesamten Inhalt markieren
9. In einem Dokument nach einem Wort suchen
10. Ganz ans Ende eines langen Dokuments springen

**Je 1 P**

## 3. Programme & Browser – 7 P

Wähle die **passendste Tastenkombination**.

1. Du möchtest in Word ein neues Dokument erstellen.  
   **Ctrl + N / Ctrl + T / Ctrl + W**

2. Du möchtest im Browser einen neuen Tab öffnen.  
   **Ctrl + N / Ctrl + T / Ctrl + L**

3. Du hast einen Browser-Tab versehentlich geschlossen und möchtest ihn zurückholen.  
   **Ctrl + Shift + T / Ctrl + T / Ctrl + Shift + N**

4. Du möchtest die aktuelle Webseite neu laden.  
   **F5 / Ctrl + F / Win + D**

5. Du möchtest sofort die gesamte Adresse im Browser markieren.  
   **Ctrl + L / Ctrl + F / Ctrl + T**

6. Du möchtest zum nächsten geöffneten Browser-Tab wechseln.  
   **Ctrl + Tab / Alt + Tab / Ctrl + T**

7. Du möchtest zum vorherigen Browser-Tab wechseln.  
   **Ctrl + Shift + Tab / Ctrl + Tab / Ctrl + Shift + T**

**Je 1 P**

## 5. Nicht verwechseln

### A) Ctrl + Tab und Alt + Tab

- **Ctrl + Tab:** zwischen Tabs innerhalb eines Programms bzw. Browsers wechseln.
- **Alt + Tab:** zwischen geöffneten Programmen/Fenstern wechseln.

**Je sinnvoll erklärter Unterschied 1 P.**

### B) Ctrl + W und Alt + F4

- **Ctrl + W:** typischerweise aktuellen Tab bzw. aktuelles Dokument schliessen.
- **Alt + F4:** aktives Fenster bzw. Programm schliessen.

**Je sinnvoll erklärter Unterschied 1 P.**

## 6. Transfer

### A) Präsentation vorbereiten

**Alt + Tab.** Damit kann direkt zwischen Browser und PowerPoint bzw. anderen geöffneten Programmen gewechselt werden.

- richtige Tastenkombination: **1 P**
- sinnvolle Begründung: **1 P**

### B) Platz kurz verlassen

**Win + L.** Der Computer wird gesperrt, während die geöffneten Programme und Dokumente erhalten bleiben.

- richtige Tastenkombination: **1 P**
- sinnvolle Begründung: **1 P**
